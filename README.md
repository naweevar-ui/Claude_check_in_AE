# เช็คชื่อ Claude AI

**เวอร์ชัน 1.7.0** · อัปเดต 14/11/2026

เว็บใช้งานจริง: https://naweevar-ui.github.io/Claude_check_in_AE/

เว็บเช็คชื่อผู้เข้าอบรม ธีมเกมสีเหลืองไข่กับฟ้าอ่อน ผู้เรียนแตะชื่อตัวเอง เซ็นชื่อหรือถ่ายรูปยืนยัน แล้วระบบจะบันทึกเวลาเข้าเรียนลง **Google Sheet** ให้อัตโนมัติ พร้อมบอกว่าใครตรงเวลาหรือมาสาย

- หน้าเว็บเป็นไฟล์ static ใช้ **GitHub Pages** เปิดได้ฟรี
- ข้อมูลทั้งหมดเก็บใน Google Sheet ของคุณเอง ผ่าน **Google Apps Script**
- ลายเซ็นและรูปถ่ายเก็บไว้ในโฟลเดอร์ Google Drive ชื่อ “ลายเซ็นและรูปเช็คชื่อ”
- ทุกเครื่องที่เปิดเว็บเห็นข้อมูลเดียวกัน หน้าเว็บดึงข้อมูลใหม่ทุก 15 วินาที

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บเช็คชื่อ |
| `config.js` | ใส่ URL ของ Apps Script เพื่อเชื่อมกับ Google Sheet |
| `apps-script/Code.gs` | โค้ดฝั่ง Google Sheet (นำไปวางใน Apps Script) |
| `apps-script/appsscript.json` | ค่าตั้งของ Apps Script (เขตเวลา Asia/Bangkok) |

## นำเข้ารายชื่อจาก Excel

เปิด “จัดการรายชื่อและสรุปผล” ท้ายหน้าเว็บ แล้วกด “เลือกไฟล์ Excel หรือ CSV” ใช้ไฟล์ที่ export จากแบบฟอร์มลงทะเบียนได้เลย ระบบอ่านชื่อ บริษัท เบอร์โทร อีเมล LINE และคนที่ 2–5 ให้ แล้วแสดงตัวอย่างก่อนกดนำเข้า ถ้าเชื่อม Google Sheet แล้ว รายชื่อจะถูกเขียนลงชีต “รายชื่อ” ด้วย ถ้ายังไม่เชื่อม รายชื่อจะเก็บไว้ในเบราว์เซอร์ของเครื่องนั้น

> การอ่านไฟล์ Excel ใช้ไลบรารี SheetJS จาก cdnjs จึงต้องต่ออินเทอร์เน็ตตอนอัปโหลด

## ขั้นตอนที่ 1: เตรียม Google Sheet

1. สร้าง Google Sheet ใหม่ เช่น ตั้งชื่อว่า “เช็คชื่อ Claude AI”
2. ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดจาก `apps-script/Code.gs` แทน กดบันทึก
4. (ไม่บังคับ) ไปที่ **Project Settings** เปิด “Show appsscript.json” แล้ววางเนื้อหาจาก `apps-script/appsscript.json`
5. เลือกฟังก์ชัน `setup` ที่แถบด้านบน แล้วกด **Run** หนึ่งครั้ง Google จะขอสิทธิ์เข้าถึง Sheet และ Drive ให้กดอนุญาต
6. กลับไปที่ Sheet จะมี 3 แท็บเกิดขึ้น
   - **รายชื่อ**: มีคอลัมน์ รหัส · ชื่อ-นามสกุล · บริษัท · โทร · อีเมล · LINE · ติดต่อผ่าน ใส่ข้อมูลตั้งแต่แถว 2 ลงมา หรือนำเข้าไฟล์ `roster-for-google-sheet.csv` (ไฟล์ > นำเข้า > อัปโหลด > แทนที่ชีตปัจจุบัน) คอลัมน์รหัสเว้นว่างได้ ระบบจะเติมให้เอง ส่วน “ติดต่อผ่าน” ใช้กับคนที่ลงทะเบียนมาพร้อมผู้ประสานงาน
   - **บันทึกเช็คชื่อ**: ระบบจะเขียนข้อมูลลงแท็บนี้ทุกครั้งที่มีคนเช็คชื่อ
   - **ตั้งค่า**: เวลาเริ่มเรียน ค่าเริ่มต้นคือ 12:00

## ขั้นตอนที่ 2: เปิดใช้เป็น Web App

1. ใน Apps Script กด **Deploy > New deployment**
2. กดรูปเฟือง เลือกประเภท **Web app**
3. ตั้งค่า
   - Execute as: **Me**
   - Who has access: **Anyone**
4. กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
5. เปิดไฟล์ `config.js` แล้ววาง URL ลงไป

```js
window.CHECKIN_CONFIG = {
  API_URL: "https://script.google.com/macros/s/xxxxxxxx/exec"
};
```

> ถ้าแก้โค้ดใน `Code.gs` ภายหลัง ต้องกด **Deploy > Manage deployments > Edit > Version: New version** ทุกครั้ง URL จะยังเป็นอันเดิม

## ขั้นตอนที่ 3: อัปโหลดขึ้น GitHub และเปิด GitHub Pages

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (หรือใช้ `git push`)
3. ไปที่ **Settings > Pages** เลือก Source เป็น **Deploy from a branch**, Branch **main**, โฟลเดอร์ **/ (root)** แล้วกด Save
4. รอสักครู่ จะได้ลิงก์เว็บ เช่น `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`

## ข้อมูลที่บันทึกลง Google Sheet

แท็บ **บันทึกเช็คชื่อ** มีคอลัมน์ดังนี้

วันที่ · รหัส · ชื่อ-นามสกุล · เวลาเข้า · สถานะ (ตรงเวลา/มาสาย) · สาย (นาที) · วิธียืนยัน (เซ็นชื่อ/ถ่ายรูป) · ลิงก์ลายเซ็น/รูป · ตัวอย่างภาพ · บันทึกเมื่อ

- ระบบใช้เวลาของเซิร์ฟเวอร์ Google เป็นเวลาเข้าเรียน คนเช็คชื่อจึงแก้เวลาจากเครื่องตัวเองไม่ได้
- เช็คชื่อตั้งแต่ 1 นาทีหลังเวลาเริ่มเรียนนับว่ามาสาย เช่น เริ่ม 12:00 น. เช็คชื่อ 12:01 น. นับว่าสาย 1 นาที
- ถ้ากดยกเลิกการเช็คชื่อ แถวนั้นจะถูกลบออกจากชีต แต่ไฟล์ภาพยังอยู่ใน Drive

## ข้อควรรู้

- **ใครเปิดเว็บก็เห็นชื่อ บริษัท เบอร์โทร อีเมล และ LINE ของผู้เข้าอบรม** เพราะหน้าเว็บดึงข้อมูลเหล่านี้มาแสดง ควรแชร์ลิงก์เว็บเฉพาะในกลุ่มผู้เข้าอบรม และแจ้งผู้เข้าอบรมก่อน ถ้าไม่ต้องการให้แสดงข้อมูลติดต่อ ให้ลบคอลัมน์ โทร · อีเมล · LINE ในชีต "รายชื่อ" ออก (เว้นว่างไว้)
- **อย่าอัปโหลดไฟล์รายชื่อขึ้น GitHub** ถ้า repository เป็นแบบ Public คนทั่วไปจะเห็นได้ ให้เก็บรายชื่อไว้ใน Google Sheet อย่างเดียว ไฟล์ `.gitignore` กันไฟล์ `.csv` และ `.xlsx` ไว้ให้แล้ว
- ใครมีลิงก์เว็บก็เช็คชื่อได้ เหมาะกับการใช้ในห้องเรียน ไม่เหมาะกับข้อมูลที่ต้องการความปลอดภัยสูง
- ถ้าบัญชี Google Workspace ขององค์กรปิดการแชร์ไฟล์ด้วยลิงก์ ภาพตัวอย่างในชีตและบนเว็บจะไม่แสดงสำหรับคนอื่น แต่ไฟล์ภาพยังเก็บอยู่ใน Drive ครบ
- ถ้ายังไม่ใส่ URL ใน `config.js` หน้าเว็บจะทำงานแบบเครื่องเดียว เก็บข้อมูลไว้ในเบราว์เซอร์ของเครื่องที่เปิด
